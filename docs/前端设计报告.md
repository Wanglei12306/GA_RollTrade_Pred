# 前端设计报告

> GA RollTrade — Web 可视化交互界面

---

## 1. 设计概述

### 1.1 设计目标

本系统前端为量化交易策略分析提供直观、高效的 Web 交互界面。设计目标包括：

- **清晰的业务流程引导**：按照"数据导入 → 参数配置 → 遗传寻优 → 回测展示"四步工作流引导用户操作
- **专业的量化可视化**：通过 ECharts 图表库展示 K 线走势、买卖信号、资金曲线、回撤分析等专业量化图表
- **简洁的操作体验**：左侧固定导航、表单默认值、一键操作等设计降低使用门槛
- **响应式适配**：适配桌面端不同分辨率，保证核心功能可用

### 1.2 技术选型

| 技术 | 选型 | 版本 | 说明 |
|------|------|------|------|
| 模板引擎 | Thymeleaf | Spring Boot 内置 | 服务端渲染，与 Spring MVC 无缝集成 |
| 图表库 | ECharts | 5.5.0 | 国产成熟图表库，CDN 引入 |
| 样式方案 | 原生 CSS | — | CSS 自定义属性 + Grid 布局，无第三方框架 |
| 脚本 | 原生 JavaScript | ES6+ | 无框架依赖，Fetch API 异步通信 |
| 字体 | Microsoft YaHei + Segoe UI | — | 系统原生字体，无需额外加载 |

### 1.3 设计原则

- **零前端构建**：无 npm/webpack/打包流程，Thymeleaf 直接渲染 + 原生 JS + CDN 图表库
- **SSR 为主 + CSR 为辅**：页面骨架和导航由服务端渲染，数据和图表由前端异步加载
- **语义化结构**：HTML5 语义标签 + CSS 组件化命名
- **设计标记化**：CSS 自定义属性统一色彩、间距、阴影体系

│ └─────────────────────────────┘             │

**交互流程**：

```
用户点击"上传 CSV" → FormData 异步 POST /api/upload
                   → 成功：显示数据预览面板（指标卡片 + ECharts 折线图 + 表格）
                   → 失败：红色错误提示

用户点击"加载示例" → GET /api/sample
                   → 同上预览流程

页面初始化 → GET /api/preview
           → 若已有数据则自动展示预览
```

**前端技术细节**（data.js）：
- 使用 `FormData` + `fetch` 实现异步文件上传，无需页面跳转
- ECharts 收盘价折线图：category 轴（日期）+ value 轴（价格），蓝色折线
- 预览面板初始隐藏（`display:none`），上传成功后才展示
- 三种提示样式：error（红色）、success（绿色）、info（蓝色）

## 5. JavaScript 交互设计

### 5.1 架构概览

```
data.js (数据管理页)
├── init()                    页面初始化，检查已有数据
├── postUpload()              CSV 文件异步上传
├── loadSample()              加载示例数据
├── renderPreview(data)       渲染数据预览面板
│   ├── 指标卡片（行数/起止时间）
│   ├── ECharts 收盘价折线图
│   └── 前 10 行数据表格
└── showAlert(msg, type)      提示信息

result.js (回测结果页)
├── init()                    页面初始化，GET /api/result
├── render(report)            主渲染入口
│   ├── renderPrice()         价格+信号图
│   ├── renderIndicators()    指标信号曲线
│   ├── renderEquity()        资金曲线对比
│   ├── renderDrawdown()      回撤曲线
│   ├── renderDrawdownDist()  回撤分布直方图
│   ├── renderCompare()       策略对比表
│   ├── renderTrades()        交易明细表
│   ├── renderWindows()       滚动窗口表
│   └── renderAnnual()        年度收益表
├── 格式化工具函数
│   ├── pct(v)                百分比格式化
│   ├── num(v, d)             数字格式化
│   └── cls(v)                正负颜色类名
├── metric(label, value)      指标卡片 HTML 生成
└── showAlert(msg, type)      提示信息
```

### 5.2 数据流

```
┌──────────┐   fetch    ┌──────────────┐   JSON    ┌──────────┐
│ 前端页面  │ ────────→  │ REST API     │ ────────→ │ 后端服务  │

└──────────┘   JSON     └──────────────┘           └──────────┘
     │
     ▼
┌──────────┐
│ ECharts  │  setOption({...}) 渲染图表
│ 实例     │
└──────────┘
```

### 5.3 错误处理

```javascript
// 统一错误处理模式
try {
    const res = await fetch("/api/xxx");
    const data = await res.json();
    if (!res.ok) {
        showAlert(data.error || "操作失败", "error");
        return;
    }
    // 正常处理...
} catch (e) {
    showAlert("操作失败：" + e.message, "error");
}
```

三种反馈形式：
1. **页面级提示**：红色/绿色/蓝色 alert 横幅，位于内容区顶部
2. **空状态提示**：无数据/无结果时的引导性提示文字
3. **加载状态**：内容区初始隐藏（`display:none`），数据就绪后展示

## 8. 设计总结

本前端系统以"**简洁实用**"为核心设计理念，在无前端构建工具链的前提下，基于 Thymeleaf + 原生 CSS + 原生 JavaScript + ECharts CDN 构建了完整的量化策略分析交互界面。

关键设计特点：

1. **零依赖前端**：无 npm/webpack/打包流程，降低项目复杂度，聚焦业务逻辑
2. **CSS 设计标记化**：10 个 CSS 自定义属性统一色彩体系，修改主题色只需改 2 个变量
3. **组件化思维**：按钮、面板、表单、指标卡片、标签、提示等 15+ 个可复用 CSS 组件
4. **渐进增强**：SSR 渲染页面骨架（导航、面板结构），CSR 异步加载数据（图表、表格），保证首屏速度
5. **三级响应式**：1100px / 820px / 560px 三级断点，桌面端全分辨率适配
6. **ECharts 专业图表**：7 组图表覆盖量化分析全场景（K线、信号、资金曲线、回撤分析、分布统计）
7. **用户引导清晰**：四步工作流 + 默认参数 + 一键操作 + 清晰的错误/空状态提示
