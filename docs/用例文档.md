# 基于遗传算法的量化策略分析系统用例文档

## 1. 文档说明

### 1.1 编写目的

本文档用于描述“基于遗传算法的量化策略分析系统”的主要用户角色、系统用例、业务流程和异常处理场景，为后续系统设计、编码实现、测试用例编写和项目验收提供依据。

### 1.2 系统范围

本系统为 Java Web 端量化策略分析系统，主要支持用户上传股票或期货历史 K 线数据，配置遗传算法和技术指标参数，执行滚动窗口训练与预测，完成策略回测，并通过 Web 页面查看行情、交易信号和回测结果。

第一版系统不接入真实交易账户，不执行真实下单操作，所有买卖信号仅用于历史回测和策略分析。

## 2. 参与者说明

| 系统管理员 | 维护系统运行环境、管理样例数据和系统配置 |

| 后置条件  | 系统保存遗传算法运行参数 |

#### 基本流程

1. 用户进入遗传算法参数配置区域。
2. 用户设置种群规模。
3. 用户设置迭代次数。
4. 用户设置交叉概率。
5. 用户设置变异概率。
6. 用户设置适应度函数权重或使用系统默认权重。

#### 参数说明

| 参数    | 说明                      |
| ----- | ----------------------- |
| 种群规模  | 每一代策略个体数量               |

| 交叉概率  | 个体之间交换编码片段的概率           |
| 变异概率  | 个体随机变化的概率               |

- 如果种群规模小于系统最小值，系统提示参数过小。
- 如果迭代次数过大，系统提示运行时间可能较长。
- 如果概率参数不在 0 到 1 之间，系统提示输入错误。

## 4.7 UC-07 执行遗传算法优化

| 项目    | 内容                  |
| ----- | ------------------- |
| 用例编号  | UC-07               |
| 用例名称  | 执行遗传算法优化            |
| 主要参与者 | 用户 |
| 前置条件  | 已上传数据，已配置指标池和遗传算法参数 |
| 后置条件  | 系统生成当前训练窗口下的最优策略    |
| 优先级   | 高                   |

#### 基本流程

1. 用户点击“开始优化”或“开始回测”按钮。
2. 系统读取当前训练窗口数据。
3. 系统根据指标池初始化种群。
4. 系统计算每个个体对应策略的适应度。
5. 系统执行选择、交叉和变异操作。
6. 系统迭代更新种群。
7. 系统输出当前窗口的最优策略。

#### 后置结果

最优策略应包含：

- 启用的技术指标。
- 各指标参数。
- 指标融合权重。
- 买入、卖出阈值。
- 适应度评分。

#### 异常流程

- 如果训练数据不足，系统停止优化并提示原因。
- 如果适应度计算异常，系统记录错误并提示用户检查数据。
- 如果运行时间较长，系统应显示运行中状态。

## 4.8 UC-08 执行滚动预测

| 项目    | 内容              |
| ----- | --------------- |
| 用例编号  | UC-08           |
| 用例名称  | 执行滚动预测          |
| 主要参与者 | 用户 |
| 前置条件  | 系统已完成至少一轮遗传算法优化 |
| 后置条件  | 系统生成各预测窗口内的交易信号 |
| 优先级   | 高               |

#### 基本流程

1. 系统使用当前训练窗口得到的最优策略。
2. 系统将该策略应用到未来预测窗口数据。
3. 系统生成预测窗口内的买入、卖出和持仓信号。
4. 系统保存本轮预测结果。
5. 系统将时间窗口向前滚动一个步长。
6. 系统重复训练与预测流程，直到数据结束。

#### 关键约束

- 当前预测窗口数据不得参与当前训练窗口优化。
- 每一轮训练和预测必须严格按照时间顺序执行。
- 系统应记录每轮窗口的训练时间段、预测时间段和最优策略。

#### 异常流程

- 如果后续数据不足一个完整预测窗口，系统可跳过该窗口或提示数据不足。
- 如果某轮优化失败，系统应记录失败窗口并继续或终止运行。

## 4.9 UC-09 执行策略回测

| 项目    | 内容            |
| ----- | ------------- |
| 用例编号  | UC-09         |
| 用例名称  | 执行策略回测        |
| 主要参与者 | 用户 |
| 前置条件  | 系统已生成滚动预测交易信号 |
| 后置条件  | 系统生成回测结果和交易记录 |
| 优先级   | 高             |

#### 基本流程

1. 系统读取全部预测窗口产生的交易信号。
2. 系统根据初始资金创建账户状态。
3. 系统按时间顺序处理买入、卖出和持仓信号。
4. 系统计算每笔交易的成本、收益和持仓变化。
5. 系统生成资金净值曲线。
6. 系统计算回撤曲线。
7. 系统生成最终回测绩效指标。

#### 回测指标

| 指标    | 说明          |
| ----- | ----------- |
| 累计收益率 | 回测期总收益      |
| 年化收益率 | 年化后的收益水平    |
| 最大回撤  | 资金净值最大下跌幅度  |
| 夏普比率  | 单位风险收益能力    |
| 胜率    | 盈利交易占比      |
| 盈亏比   | 平均盈利与平均亏损之比 |
| 交易总次数 | 完整交易次数      |

#### 异常流程

- 如果交易信号为空，系统提示“暂无可回测信号”。
- 如果初始资金不合法，系统提示用户修改。
- 如果手续费率不合法，系统提示用户修改。

## 5. 主要业务场景

### 5.1 场景一：用户完成一次完整策略回测

1. 用户访问系统首页。
2. 用户进入数据管理页面。
3. 用户上传股票或期货 CSV 历史数据。
4. 系统解析并展示数据预览。
5. 用户进入参数配置页面。

7. 用户配置遗传算法参数。
8. 用户配置 3 个月训练、1 个月预测的滚动窗口。
9. 用户点击开始回测。
10. 系统执行遗传算法优化、滚动预测和策略回测。
11. 系统展示资金曲线、回撤曲线、买卖点和绩效指标。

### 5.2 场景二：用户发现上传数据格式错误

4. 系统提示“缺少必要字段：close”。
5. 用户修改文件后重新上传。
6. 系统解析成功并展示数据预览。

### 5.3 场景三：用户查看项目成果

1. 用户访问系统首页。
