## 3. 初次上传操作流程

进入项目根目录：

```powershell
cd "C:\Users\34173\Desktop\基于遗传算法的量化策略分析系统"
```

初始化 Git 仓库：

```powershell
git init
```

添加远程仓库：

```powershell
git remote add origin https://github.com/Wanglei12306/GA_RollTrade_Pred.git
```

创建并切换到上传分支：

```powershell
git checkout -b yangshuailu_branch
```

添加项目文件：

```powershell
git add .
```

提交初始版本：

```powershell
git commit -m "initial project upload"
```

推送到远程分支：

```powershell
git push -u origin yangshuailu_branch
```

## 4. 注意事项

- 本次上传为初次上传，不需要先从远程分支合并历史代码。
- 如果远程分支已存在且包含他人代码，推送前应先确认是否需要拉取合并。
- 若 GitHub 提示登录或认证失败，需要使用拥有该仓库写入权限的 GitHub 账号。
- `.gitignore` 中已忽略 Word 临时文件、IDE 配置文件和 Java 编译产物。
